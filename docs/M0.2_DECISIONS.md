# M0.2 Bootstrap Decisions

Date: 2026-11-20 (updated 2026-11-23)
Status: Foundation implemented locally and clean-copy reproducibility verified; M0.2 acceptance is **not complete** because GitHub-hosted CI execution and branch-protection evidence are still missing (no remote exists).

## Adopted defaults

- Repository root: this EIS directory only; no remote and no submodules.
- Language baseline: Python 3.12; supported range Python 3.11–3.12 (ADR-032). Python 3.13 and 3.14 are not supported.
- Package: one `src/eis` distribution using uv and hatchling, with a committed `uv.lock`.
- Policy: deny by default; no initial allow rules; exact-match rules only, wildcards rejected.
- Runtime data: platform application-data directory, outside the repository.
- Registered project roots: none by default; future values are local runtime configuration and are never committed.
- Model: no provider enabled by default. An external OpenCode/OpenAI/Gemini/Anthropic/xAI provider can be configured explicitly through environment variables; Ollama is optional and not required (ADR-033, ADR-034). Model tag, context size and concurrency remain local user choices.
- Untrusted execution: T2 isolation is required; when T2 is unavailable the operation must be refused. Windows T1 is not a security boundary.
- Product identity: single-user v1; team/RBAC deferred (ADR-031).
- Retention baseline: closed sessions 7 days, audit records 365 days, engineering knowledge until deleted.
- Code licence: Apache-2.0, approved by the project owner on 2026-11-20 (ADR-021). `LICENSE` and `NOTICE` are present.
- Vision document: retained in the workspace but ignored by Git pending publication review.
- Obsidian: no vault path is configured and no export is enabled.

## Implemented in M0.2

- `pyproject.toml`, `.python-version`, `uv.lock`, Apache-2.0 `LICENSE` and `NOTICE`.
- `src/eis` skeleton: configuration defaults, policy loader/evaluator, privacy guard, FastAPI factory, Typer CLI and `python -m eis` entry point.
- `policies/default.json` and JSON Schemas for policy and policy decisions.
- Privacy guard used by tests, pre-commit and CI: drive/home/UNC paths, runtime data files and secret-shaped values.
- CI jobs for lint, types, tests (Windows/Linux/macOS × Python 3.11/3.12), security audit, privacy and package build. Actions are pinned to full commit SHAs cross-checked against upstream tags with `git ls-remote`: `actions/checkout` v6, `actions/setup-python` v6, `astral-sh/setup-uv` v7 and `gitleaks/gitleaks-action` v2. Reviewed 2026-11-23: `permissions: contents: read` only, `persist-credentials: false` on every checkout, `timeout-minutes` on every job, `uv lock --check` added, `--locked` on every `uv sync`/`uv run`, and no `.env`, provider or repository-secret dependency. These properties are asserted by `tests/test_ci_workflow.py`, and the workflow file parses as valid YAML.
- Baseline tests for repository-root protection, vision-document exclusion, runtime-data exclusion, deny-by-default policy, generated OpenAPI, CLI/API import contracts and configuration defaults.
